# v0.4 safety foundation

## Report collection

`audit-all.sh` invokes children with Bash, so a fresh checkout does not require executable bits on script files. Both `audit-all.sh` and `inventory-all.sh` use `umask 077` before creating local reports and return non-zero if any required subreport fails. Existing report files are not deleted.

## Reinstall preflight

The preflight distinguishes:
- 0: no blocking failures and physical separation check completed
- 1: failure detected or invalid arguments
- 2: INCONCLUSIVE because backing block devices or physical parent disks cannot be resolved

Non-zero output must halt a prospective reinstall. Exit zero is not proof of an adequate or restorable backup; inspect files manually, protect all user accounts, and independently verify the target drive.

## Verification

Run `bash tests/safety-smoke.sh` to exercise mocked unknown-device and same-path cases without touching real block devices.

## Rollback

Revert the PR commit to restore the earlier script behavior. No system configurations, disks, mounts, backup contents or existing report directories are modified by this patch. The more conservative preflight exit status may affect callers that previously treated unknown devices as success.
